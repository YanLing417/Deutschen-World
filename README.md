### 怎么自己看这些页面

> **最快的方式**：双击项目根目录下的 **打开主页.lnk**（Windows 快捷方式，中文名，图标为文档样式），

| 方式 | 做法 |
|---|---|
| **最简单** | 双击 `docs/home.html`，从主页进入各个栏目（页面不依赖服务器，`file://` 直接可用） |
