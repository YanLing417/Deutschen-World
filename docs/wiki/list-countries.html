不列颠联邦共和国

已确定1066 诺曼征服 — 至今；1272-1945 为绝对君主制；19

本世界线的罗曼-法兰西高文化正宗保存者。大陆法兰克被日耳曼化后，罗曼-法兰西宫廷文明逆流回不列颠，使英格兰走上与法兰克相反的绝对君主制道路，直至1945年战败才被迫民主化。

东洲（新大洲，正式名称待定）

待定— 至今

S2 提出的第三大洲，也是最重要的新设定。核心概念不是“中华文明圈”这么简单，而是“泛中华文明圈—印度文明圈”，其历史联系来自印度佛教 → 犍陀罗 → 西域 → 中亚 → 中国 → 蒙古/西藏 → 东亚。西域佛教成为这个新大洲文明连续性的关键历史桥梁。

两河王国

待定

20 世纪近东民族国家格局中的两河国家，以巴格达为都——阿拔斯哈里发国的故地。

中国

已确定— 至今

本世界线中拥有一条更强的西向文明轴：中国内地 → 河西走廊 → 敦煌 → 塔里木盆地 → 天山 → 中亚佛教世界。“西域”不再只是边疆，而是中国文明向中亚投射影响的长期文明走廊。

丹麦-挪威

已确定— 17世纪

宗教战争中“丹麦-低地阶段（1625-1629）”的介入方，丹麦-挪威新教国王介入战争。

亚洲（文明大洲）

已确定— 至今

S2 把罗斯兀鲁思整体划入亚洲，同时包括撒哈拉以北非洲东部、近东、中东、穆斯林西亚，形成“罗斯兀鲁思—西亚—伊斯兰文明空间”。

伊斯兰世界（区域文明体集合）

已确定7世纪 — 至今

本世界线的区域文明体集合。S1 明确本世界并非“消灭伊斯兰世界”，而是重新划定伊斯兰文明的东部边界：伊斯兰化止步于更西侧，西域/塔里木保持佛教。其西线则在伊比利亚被逐出，但北非西部到19—20世纪仍为伊比利亚国家的一部分。西亚（阿拉伯—伊朗—两河—安纳托利亚）仍以伊斯兰文明为主。

伊朗（伊斯兰什叶派波斯）

已确定7世纪 — 至今

「波斯」概念在本世界线中被撕裂为两支：一支是伊斯兰化的什叶派波斯，即本条目「伊朗」；另一支是退守河中及以东、保持佛教的「西域-波斯残余」（见 C_PERSIA_BUDDHIST）。波斯曾抵御伊斯兰入侵，后因内乱而退守河中及以东，伊朗遂成为伊斯兰文明东端的什叶派国家，与逊尼派的阿拉伯—安纳托利亚体系长…

伊比利亚共和国（第五共和国后体制）

已确定伊比利亚王国 → 伊比利亚第一共和国 → 第一帝国 → 第二共和国

本世界线的秩序挑战者与第三文明中心。1789年伊比利亚-奥克大革命建立革命帝国，席卷南欧、占领奥克、攻入那不勒斯、迫使神圣罗马帝国解散。其历史功能是不断打破德意志-法兰克之间的平衡。

伊比利亚王国

已确定— 1789（伊比利亚-奥克大革命中推翻）

用户本轮补充设定的实体。由西班牙-阿拉贡（及奥克王国）为起点，逐步统一伊比利亚各基督教王国，并南下北非驱逐穆斯林，最终建立伊比利亚王国。该王国在1789年伊比利亚-奥克大革命中被推翻，此后进入共和国/帝国反复更替的时代。

伊比利亚第一共和国

已确定1789 — 约1804（转为伊比利亚第一帝国）

伊比利亚大革命推翻王国后建立的第一个共和政体，是「伊比利亚共和国—帝国反复更替」序列的起点。革命军自伊比利亚与奥克出发席卷南欧，攻入那不勒斯，迫使神圣罗马帝国解散。该政体后由第一帝国取代。

伊比利亚第一帝国

已确定约1804 — 1815（被反伊比利亚同盟击败）

伊比利亚革命政权的帝国阶段，也是其扩张的顶点。它把大革命推向全欧，但其远征罗斯兀鲁思最终失败——这与现实史中拿破仑远征的失败同构，是伊比利亚由盛转衰的转折。1815 年被法兰克、普热米斯尔、英国、罗斯兀鲁思组成的反伊比利亚同盟击败。

伊比利亚第三共和国（1871—1940）

已确定1871 — 1940（被法兰克与德意志击败）

伊比利亚第二帝国于 1871 年被新成立的德意志帝国击败后，伊比利亚转入第三共和国。它是本世界线中存续最久、出场最频繁的伊比利亚政权：一战中加入协约方（与英帝国、罗斯兀鲁思、美国同侧）对中欧作战；二战中再度站到协约国一侧，结果于 1940 年被法兰克与德意志击败，第三共和国就此终结。其在奥克…

伊比利亚第二共和国

已确定1815 — 19世纪中叶（转为伊比利亚第二帝国）

拿破仑战争后重建的共和政体。它接过革命留下的民族主义、立宪主义与共和主义遗产，但中央集权并未松动——S2 所记「中央集权从未真正逆转」正由此延续。其长臂管辖一度伸至南意大利那不勒斯与罗马。

伊比利亚第二帝国

已确定19世纪中叶 — 1871（被德意志帝国击败）

第二共和国之后的帝制阶段。它的势力范围一度覆盖那不勒斯与罗马，1871 年普热米斯尔攻入这两地并在罗马加冕，第二帝国同时被击败——德意志帝国成立之日，即伊比利亚第二帝国终结之时。

伊比利亚第五共和国（1960— ）

已确定1960 — 至今

第四共和国因非洲殖民地危机覆灭后，伊比利亚于 1960 年重建为第五共和国。与第四共和国相反，本期总统权力重新加强，中央集权传统回归，同时保留战后确立的民主化框架——这正是 S2 所概括的「国家可以很强，但权力必须民主化」。本词条即现行「伊比利亚共和国」的正式分期名称。

伊比利亚第四共和国（1945—1954）

已确定1945 — 1954（因非洲殖民地危机覆灭）

战后由胜利方推动建立的议会制共和国，是伊比利亚政治史上总统权力最弱的阶段：国家高度议会化，总统权力受限。它面临的核心难题是非洲殖民地危机——北非西部在法律上属伊比利亚本土行政体系，但战后的民族主义浪潮使这一体制难以为继。1954 年前后危机爆发，第四共和国覆灭。

伊比利亚被占领与过渡期（1940—1945）

已确定1940 — 1945（战后建立第四共和国）

第三共和国于 1940 年战败后，伊比利亚进入被占领与过渡管理期，直至 1945 年二战结束。这五年是伊比利亚政治体制的断点：旧共和国的中央集权与殖民体系在此期间崩解，为战后高度议会化的第四共和国铺路。1945 年，胜利方（德意志等）推动伊比利亚民主化，第四共和国由此建立。

低地联合省

已确定1625 — 至今（1871后作为尼德兰州、阿姆斯特丹城市州并入德意

宗教战争中凭海军和金融坚持抵抗并宣布独立，1648年正式独立为加尔文宗共和国。19世纪后并入德意志统一进程，成为德意志联邦的尼德兰州与阿姆斯特丹城市州。

叙利亚共和国

待定

20 世纪近东民族国家格局中的叙利亚国家。是法兰克东方学传统在 20 世纪的直接接触对象。

叙利亚地区

已确定7世纪 — 至今

东地中海沿岸的伊斯兰地区，十字军东征的主要战场。S1 特别指出法兰克“拥有地中海传统……拥有北非、黎凡特传统影响”，且首都（原文作“巴黎”，本库统一作帕里斯）有神学、历史、东方学传统，因此法兰克自然会成为“欧洲研究东方世界的重要文明”——其直接接触面即叙利亚与黎凡特。

君士坦丁堡（海峡政治体，通称拜占庭）

已确定— 至今

希腊人主导的基督教城邦—海峡政治体，通称「拜占庭」，以控制海峡通行权立国，靠海峡通行税与贸易维生。它与安纳托利亚突厥帝国长期对峙共处，是伊斯兰文明与基督教文明之间的「边界」——S1 明言「海峡是文明边界，而不是文明墙」：一个收取通行费、允许双方通行的城邦，恰恰不是墙。

埃及地区

已确定7世纪 — 至今

尼罗河流域。法蒂玛王朝在此建开罗；此后历经阿尤布、马穆鲁克，1517年并入安纳托利亚突厥帝国。是东地中海与印度洋贸易的关键中转。按 S2 的大洲划分，埃及属“撒哈拉以北非洲东部”，文明地理上划入亚洲。

埃及王国

待定

20 世纪近东民族国家格局中的埃及国家，控制苏伊士地峡——东地中海与印度洋之间的关键通道。

基辅王国

已确定古罗斯 → 一战后被罗斯兀鲁思吞并 → 二战后重新独立

本世界线中乌克兰的替代者。自称古罗斯传统的真正继承者，强调基辅、东斯拉夫传统、东欧基督教、欧洲政治文化、古罗斯法律传统，以及与中欧、德意志、波罗的海的联系，越来越靠近欧洲文明。

奥克王国

已确定— 1648年前后（部分领土被伊比利亚取得）；1789年大革命后其地

用户本轮补充设定的实体：伊比利亚的前身之一。奥克语地区的政治体，与西班牙-阿拉贡同为伊比利亚统一进程的源头。1648年《维也纳和约》后法兰克在奥克地区占领后撤，伊比利亚获得部分奥克领土；1789年伊比利亚-奥克大革命即爆发于此地区。二战后法兰克获取奥克地区并设南部奥克省。

奥斯曼帝国（安纳托利亚突厥帝国）

已确定13世纪末 — 至今

安纳托利亚的突厥穆斯林帝国。本世界线中伊斯兰世界在东部受限于西域佛教带，因此安纳托利亚成为伊斯兰力量向欧洲方向的主要压力来源。S1 明确“安纳托利亚：伊斯兰与基督教并存/竞争”，且“君士坦丁堡：基督教文明核心之一”，故本帝国与海峡基督教政治体长期对峙共处。

德意志共和国（1918—1945）

已确定1918 — 1945（二战中取消不平等条约、收复波兰，其后重建联邦

一战战败后普热米斯尔王朝结束，德意志由帝国转为共和政体。它在两次大战之间保住了学院、工厂、乐团与咖啡馆，却没有保住国家的能力——直到二战中取消不平等条约、收复波兰，并最终重建为统一联邦制民主共和国。

德意志联邦共和国

已确定1945 — 至今（1945 年重建为联邦制民主共和国；1871—1

本世界线的东部日耳曼政治体与泛德意志文明核心。普热米斯尔家族自奥托卡二世起推行集权与德意志化，16世纪皈依新教，17世纪成为泛德意志新教世界最高世俗领袖。1866年击败法兰克确立小德意志方案，1871年在罗马加冕成立帝国。一战战败后建立维也纳德意志共和国，二战后重建为联邦制民主共和国。

教皇国

已确定— 至今（1871年罗马加冕后罗马被纳入德意志帝国；教皇国作为世俗领

宗教制度中的关键一极。1356年教皇使节参与法兰克福会议；教皇承认皇帝对法兰克教会的提名权。1871年普热米斯尔攻入罗马并在此加冕，罗马自此成为德意志帝国的加冕圣城。

欧洲（文明大洲）

已确定— 至今

大洲不再单纯按地质/地理连续性划分，而按长期形成的文明—历史空间划分。欧洲包括欧洲大陆 + 撒哈拉以北非洲西部。伊比利亚北非不是殖民地意义上的“非洲”，而是伊比利亚国家内部的普通行政区域，故在文明地理上属于欧洲。

法兰克共和国

已确定1918 — 1945（二战中哈布斯堡复辟）

一战战败后，哈布斯堡失去对法兰克的实际统治，法兰克由君主国立宪政体转为共和国。但这一共和国是不完善的：哈布斯堡贵族仍然渗透政府与军队。1945 年二战中哈布斯堡复辟，此共和国时期结束。

法兰克立宪君主国

已确定1272 — 1918；1945 — 至今（1918—1945 为法

本世界线的西部日耳曼政治体。由哈布斯堡的鲁道夫在卡佩绝嗣后入主，定都帕里斯，宫廷与军事德意志化。1356年《法兰克福宪章》后与德意志王冠构成不可分割的双重王冠。1871年罗马加冕后与德意志王冠分离，成为独立国家。

法兰西罗曼王国

已确定987 — 1270（卡佩直系绝嗣）

大陆北部的罗曼语政治体，本世界线中十字军东征的发动者，也是「法兰西」这一政治名称的最后载体。1270 年前后卡佩直系绝嗣后，它被哈布斯堡的法兰克所取代——此后大陆北部说日耳曼语，而它的语言与宫廷文化转入不列颠。

法蒂玛哈里发国（埃及）

已确定909 — 1171

埃及的什叶派哈里发国，以开罗为中心，势力及于叙利亚与汉志。1171年被萨拉丁推翻，埃及转入逊尼派阿尤布王朝。

瑞典

已确定— 17世纪

宗教战争中“瑞典-南德阶段（1630-1635）”的介入方，瑞典新教国王介入并与普热米斯尔结盟。

瑞士永久联邦

已确定1356 — 至今

帝国内特殊自治体，不承担帝国税和兵役，各州可保留共和制度，但对外不得与帝国敌人结盟。1648年确认独立与永久中立。同时是法兰克和普热米斯尔-德意志的角力之地，并在泛德意志语言共同体中发挥桥梁作用。

白罗斯

已确定二战结束 — 至今

二战后与基辅王国同时脱离罗斯兀鲁思，并与基辅王国组成「基辅王国—白罗斯联邦」，成为德意志/欧洲 → 基辅王国-白罗斯 → 罗斯兀鲁思 → 蒙古-西伯利亚文化圈这一文明梯度的中间环。

科尔多瓦哈里发国

已确定929 — 1031（分裂为诸泰法）

伊比利亚的穆斯林政权，8世纪起统治半岛大部，929年自立哈里发。1031年分裂为诸多泰法小国，为北方基督教诸王国的推进提供条件。此后由北非的穆拉比特与穆瓦希德两王朝先后渡海接管安达卢斯。

穆瓦希德哈里发国（及穆拉比特）

已确定11世纪 — 13世纪（1212年后在伊比利亚崩溃）

北非柏柏尔人的两个王朝，先后渡海接管安达卢斯。1212年战败后其在伊比利亚的统治崩溃，伊比利亚各基督教王国由此得以完成收复失地运动并南下北非。

罗斯兀鲁思

已确定古罗斯诸国 → 蒙古征服 → 金帐秩序 → 莫斯科王朝 → 现代罗斯

本世界线中罗斯兀鲁思的替代者。因蒙古帝国未伊斯兰化、西域佛教文明带长期存在，莫斯科诸公国并未“摆脱鞑靼枷锁”，而是继承了金帐汗国的国家机器与政治传统，形成“后基辅罗斯国家”。其文明来源被自我认定主要为蒙古-金帐体系。

美利坚合众国

待定— 至今

未崛起为超级大国，但仍是重要工业和科学力量。钢铁、石油、汽车、电气与中欧并驾齐驱。大学吸引部分欧洲流亡学者。因欧洲政治环境不同，移民结构改变，大量欧洲共和派、社会主义者、激进自由主义者迁入，使美国成为“欧洲激进共和主义的实验场”。

英格兰-诺曼底

已确定1066 — 1272（被鲁道夫击败，被逐出大陆）

金雀花王朝延长、法兰西化程度加深的跨海政权。爱德华一世为卡佩继承争夺者之一。1272年鲁道夫击败诺曼底公爵，夺取法兰西岛和香槟，英格兰-诺曼底被逐出大陆，英-法兰克竞争长期化。

蒙古帝国

已确定1200—1300崛起；金帐汗国延续至政治覆灭后由其继承者承接传统

连接中国佛教世界、西域佛教世界、伊斯兰中亚与伊朗-西亚的关键文明枢纽。本世界线中蒙古帝国未迅速伊斯兰化，且西域佛教文明带长期存在，使其在欧亚大陆北部留下的政治与文化遗产远比现实更深厚。

西亚伊斯兰文明空间

已确定— 至今

S1《1960年前后：新的亚洲文明地图》中的区域文明之一。伊斯兰文明在西亚仍为主流，但其向中亚东部与塔里木盆地的推进在本世界线中“止步于更西侧”。

西伯利亚萨满文化区

已确定— 至今

S1 亚洲宗教史新原则中的一环：西伯利亚形成“萨满传统 + 长生天传统”。这让罗斯兀鲁思向东扩张面对的不再是单纯的穆斯林汗国，而是一条草原蒙古文化圈 → 西伯利亚萨满文化 → 佛教西域 → 中国的梯度。

西域-波斯（佛教波斯残余）

已确定8世纪后 — 至今

「波斯」概念在本世界线中被撕裂为两支之一。波斯曾抵御伊斯兰入侵，但最终因内乱而退守河中及以东地区，其遗民在此保持佛教，成为「西域-波斯」。它把河中地区纳入佛教文明圈，从而与东侧的西域佛教文明带连成一片，构成伊斯兰文明与东洲佛教世界之间的过渡地带。这正是用户裁定（P5）确立的结构。

西域佛教文明带

已确定公元前后 — 至今（8-12世纪未被迅速伊斯兰化）

本世界线与现实最大的宗教史差异之一：现实中伊斯兰逐渐向中亚东部和塔里木盆地推进，龟兹等地约在12世纪前后结束佛教时代；本世界线改变这一节点，伊斯兰化止步于更西侧，天山以东佛教强、塔里木盆地佛教持续、敦煌继续作为东方佛教门户。

西法兰克王国

已确定843 — 987（卡佩家族取代加洛林）

大陆北部罗曼语政治体序列的第一阶段，也是后来「法兰西罗曼王国」的前身。本世界线中，这一支罗曼语政治体最终在 1270 年卡佩绝嗣后终结，其语言与宫廷文化则转移到不列颠（见「罗曼正统错位」）。

西班牙-阿拉贡

已确定— 17世纪

宗教战争初期属天主教联盟，后出于反哈布斯堡法兰克地缘利益加入新教联盟，形成“外交新教、内政天主教”的矛盾立场。

西班牙王国

已确定15世纪 — 16世纪初（并入西班牙-阿拉贡及奥克王国）

伊比利亚半岛中部的中央集权君主国，是伊比利亚统一进程的两大起点之一。它在收复失地运动中扩张最快，推动天主教共同身份的形成，并最终与阿拉贡合并。其首都托莱多后来成为伊比利亚王国的首都。

金帐汗国

已确定13世纪 — 政治覆灭（制度由罗斯兀鲁思继承）

本世界线中，金帐汗国并未在14世纪逐渐转变为伊斯兰汗国，而是继续保持蒙古贵族政治传统、长生天信仰、佛教、草原萨满传统、蒙古军事制度与汗国封建体系。其统治逐渐制度化、官僚化、地方化，成为莫斯科诸王公可以继承的国家机器。

阿尤布苏丹国（埃及—叙利亚）

已确定1171 — 1250（马穆鲁克取而代之）

萨拉丁建立的逊尼派苏丹国，统合埃及与叙利亚，是十字军东征时期穆斯林一方的主要政治体。1250年被马穆鲁克王朝取代。

阿拉伯—汉志地区

已确定7世纪 — 至今

麦加与麦地那两圣地所在。政治上长期为地方谢里夫政权，名义上隶属先后更替的区域强权（阿拔斯、法蒂玛、马穆鲁克、安纳托利亚突厥帝国）。红海贸易为其经济命脉。

阿拉伯王国

待定

20 世纪近东民族国家格局中的阿拉伯国家。由汉志的谢里夫政权升格而来，控制麦加、麦地那两圣地。其诞生背景是安纳托利亚突厥帝国在 20 世纪的多极格局中逐步失去对阿拉伯半岛的直接统治。

阿拉贡王国

已确定12世纪 — 16世纪初（并入西班牙-阿拉贡及奥克王国）

伊比利亚半岛东北部的君主国，伊比利亚统一进程的另一起点。与卡斯蒂利亚方向不同，阿拉贡的扩张重心在地中海与南法，因此与奥克语地区关系密切，是奥克最终卷入伊比利亚轨道的关键。

阿拔斯哈里发国（两河）

已确定750 — 1258（巴格达陷落）

以巴格达为中心的哈里发国，是伊斯兰世界逊尼派名义上的最高权威。1258年巴格达陷落于蒙古西征军，此后哈里发名义由马穆鲁克庇护。

非洲（文明大洲）

已确定— 至今

四洲划分中的第四洲。撒哈拉承担文明分界功能：撒哈拉以北西部 → 欧洲；撒哈拉以北东部 → 亚洲；撒哈拉以南 → 非洲。

马格里布（北非西部）

已确定伊斯兰化（7世纪）→ 柏柏尔诸王朝 → 伊比利亚南下驱逐穆斯林 →

北非西部。7世纪起伊斯兰化，11—13世纪由柏柏尔王朝（穆拉比特、穆瓦希德）统治并渡海接管安达卢斯。此后伊比利亚各基督教王国南下驱逐穆斯林，长期统治并基督教化、欧洲化该地区。S2 明确其“没有特殊宪制地位”，与伊比利亚半岛同属一个国家行政体系。

马穆鲁克苏丹国（埃及—叙利亚）

已确定1250 — 1517（被安纳托利亚突厥帝国取代）

由军事奴隶精英建立的苏丹国。1260年阻止蒙古西进，此后长期统治埃及与叙利亚，是东地中海与红海贸易的关键政治体。1517年并入安纳托利亚的突厥帝国。
