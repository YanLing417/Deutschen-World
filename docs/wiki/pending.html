P1　宗教—文明边界线：伊斯兰文明止于哪里？西域佛教覆盖到哪里？蒙古长生天世界向西延伸到哪里？罗斯兀鲁思何时以何方式进入非伊斯兰化的中亚？

  • - 出处：S1、S4
  • - 状态：待裁定
  • - 为何阻塞：S1 明确指出：这条线不定，俄罗斯、中国、蒙古、西域、西亚乃至君士坦丁堡的历史就无法沿同一条纵轴展开，只能停留在互相孤立的「亚洲背景设定」。它是目前唯一被设定集本身点名为「最值得钉死」的条目。

可选方案

方案A：以河中（阿姆河—锡尔河）为界

伊斯兰文明东界止于河中地区；天山以东、塔里木盆地为西域佛教带；蒙古高原为长生天+佛教+萨满；西伯利亚为萨满。

  • - 利：与 S1「伊斯兰化止步于更西侧」「河中地区：穆斯林影响强；天山以东：佛教强」完全一致；边界清晰、可用一条河与一道山脉标定，便于地图工程绘制；给波斯留出明确的东部锚点，符合 S1「伊朗：伊斯兰」
  • - 弊：中亚西部的过渡带较窄，可能显得生硬；未回答「罗斯兀鲁思何时进入中亚」这一时间维度

方案B：以天山—帕米尔为界，河中为双影响过渡带　★ 推荐

伊斯兰东界为天山—帕米尔；河中为伊斯兰与佛教双影响的过渡带；罗斯兀鲁思沿草原走廊南下介入。

  • - 利：过渡带更宽，文明梯度更自然；为罗斯兀鲁思的南下留出空间与理由；与「文明边界而非文明墙」（S1 论君士坦丁堡）的总体风格一致
  • - 弊：界线较模糊，地图绘制需要额外符号表示过渡带；过渡带的政治归属需再定一层

方案C：不定死界线，只定「权重梯度」

不设地理界线，只规定各区域的宗教权重（如河中：伊斯兰7佛教3）随时间变化。

  • - 利：最大灵活度，后续扩写不受限；适合尚未决定细节的阶段
  • - 弊：S1 明确要求「钉死这条线」，方案C 等于不执行该要求；无法支撑地图工程的边界绘制

推荐与理由

推荐：方案B：以天山—帕米尔为界，河中为双影响过渡带

方案B 严格包含方案A 的全部已确定信息（河中穆斯林影响强、天山以东佛教强），同时额外满足 S4 对罗斯兀鲁思「何时以何方式进入中亚」这一时间维度的需求，并与 S1「海峡是文明边界，而不是文明墙」的边界观一致——S1 反对的正是「墙」式的硬边界，因此一条带过渡带的边界比一条硬线更贴合既有设定。

裁定状态：用户已选：方案B：以天山—帕米尔为界，河中为双影响过渡带

P2　「罗斯兀鲁思 / 莫斯科国」的正式别名（「俄罗斯」已按 S4 要求废弃）

  • - 出处：S4
  • - 状态：待裁定
  • - 为何阻塞：S4 原文：「为避免继续使用你要求废弃的『俄罗斯』名称，以下暂以『莫斯科国』作为这个国家的工作别名……如果你之后决定正式别名不是『莫斯科国』，我们可以再全局替换。」这是唯一一个由设定集主动请求用户裁定的改名事项，且影响全部涉及该国的条目。

可选方案

方案A：保留国号「罗斯兀鲁思」，弃用一切别名

正式名与常用名统一为「罗斯兀鲁思」（Ross-Ulus）。

  • - 利：与 S4 的国号设定完全一致；避免了「莫斯科国」与首都同名的歧义；「兀鲁思」直接点明蒙古制度来源，符合本世界线的核心机制
  • - 弊：中文语境下「兀鲁思」较生僻，行文中反复出现略显拗口；缺少一个简短通称

方案B：国号「罗斯兀鲁思」，通称「罗斯」　★ 推荐

正式名为罗斯兀鲁思，行文通称「罗斯」。

  • - 利：「罗斯」简短、且与「基辅罗斯」「古罗斯」的词根衔接自然；能同时兼顾「东斯拉夫底层」与「蒙古上层」两个面向；与基辅王国的区分清晰（基辅王国≠罗斯）
  • - 弊：「罗斯」在现实史中指代范围更广，易与基辅罗斯混淆；需在术语表中明确「罗斯」在本世界线专指罗斯兀鲁思

方案C：沿用 S4 的工作别名「莫斯科国」

以「莫斯科国」为通称。

  • - 利：S4 已经用过，改动最小；地理指向明确（以莫斯科为中心）
  • - 弊：「莫斯科」本是城市名，用作国名会让首都与国名同级，行文易混；无法体现蒙古—金帐继承这一核心机制

推荐与理由

推荐：方案B：国号「罗斯兀鲁思」，通称「罗斯」

S4 的核心机制是「后基辅罗斯国家」——该国自认历史序列为「古罗斯诸国 → 蒙古征服 → 金帐秩序 → 罗斯兀鲁思」。采「罗斯」为通称，正好把「罗斯」这一词根保留在国家认同里，同时以「兀鲁思」标明其蒙古制度来源，两不偏废。方案A 最忠实但缺少通称；方案C 与首都同名，行文成本最高。

裁定状态：用户已选：方案B：国号「罗斯兀鲁思」，通称「罗斯」

P3　新设定的大洲正式名称

  • - 出处：S2、S4
  • - 状态：已被本轮补全为部分
  • - 已采纳内容：S4 给出：故称「奥洲（Orient）」，20 世纪后的现代称呼「东洲」

可选方案

方案A：正式名「东洲」，历史故称「奥洲」　★ 推荐

现代正式名用东洲，历史文献与旧地图用奥洲。

  • - 利：完全采用 S4 已给出的两个名称，无需新增设定；「故称/现代称呼」的时间差本身可以成为设定细节（旧地图 vs 新地图）；四洲名称（欧洲、亚洲、东洲、非洲）音节平衡
  • - 弊：「东洲」与「亚洲」在中文语感上略有重叠

方案B：正式名「奥洲」，东洲为俗称

正式名沿用旧称奥洲。

  • - 利：与 S2 最早提出该洲时的用词风格一致；「Orient」在印欧语中辨识度高
  • - 弊：与 S4「东洲作为20世纪后的现代称呼」的表述方向相反；在四洲并列时（欧/亚/奥/非）音近易混

方案C：新造一个名称

另拟一个非「东洲/奥洲」的正式名（如以文明特征命名）。

  • - 利：可以更准确表达「泛中华文明圈—印度文明圈」的双核心性质
  • - 弊：需新增设定，且会与 S4 已给出的两个名称并存，增加术语负担；S2 与 S4 均已用「奥洲/东洲」，另造名会造成三套称谓

推荐与理由

推荐：方案A：正式名「东洲」，历史故称「奥洲」

S4 已经给出了两个名称并明确了它们的时间分工（故称 vs 20 世纪后的现代称呼），这实质上已经完成了命名。方案A 只是把这个分工确认为正典，不引入任何新设定，符合「采纳最新设定集补充内容」的处理原则。

裁定状态：用户已选：方案A：正式名「东洲」，历史故称「奥洲」
