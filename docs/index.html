奥克省的行政地位M01

S5 整合表述：奥克地区为法兰克南部；1648 年后部分领土归伊比利亚；1789 年大革命爆发于此；1945 年法兰克设「南部奥克省」（临时性省级中间管理层，非第一级联邦单位）；1972—1978 年「奥克正常化」，1975 年为关键节点，此后该省废除，奥克各州升为普通联邦州；奥克语可作州级官方语言，法兰克语仍为联邦唯一官方语言。

被合并的原条目（4 条）
  • S0：南部奥克省「不是联邦制下普通州，而是特殊建制」，省总督由巴黎直接任命，下辖五州
  • S1：不能理解成一个单一的「奥克民族主义省」，内部高度复杂（普罗旺斯为法兰克—德意志文化支点）
  • S2：1945—1975 年的临时性省级行政层；约 1975 年后废除，原奥克州全部直接成为普通联邦州
