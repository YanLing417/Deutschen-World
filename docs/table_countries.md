## 国家详表
### 法兰克立宪君主国　`C_FRANKEN`
- **德**：Fränkisch-Konstitutionelle Monarchie　**英**：Frankish Constitutional Monarchy
- **政体**：联邦化单一制；早期宪政→成熟宪政君主制→(1918-1945)共和国→(1945-)君主立宪共和国，国王完全礼仪化
- **王朝**：哈布斯堡（Habsburg，贯穿始终）
- **宗教**：天主教（官方）
- **首都**：帕里斯
- **领土**：法兰西岛、香槟、勃艮第、洛林、阿尔萨斯南部、弗兰德斯、诺曼底、布列塔尼、加来-皮卡第、卢瓦尔、罗讷-阿尔卑斯；1945后另获南部奥克省（1975年该省废除，奥克各州升为普通联邦州）
- **语言**：法兰克语 / 西法兰克语（Fränkisch / Westfränkisch），西日耳曼语支
- **存续**：1272 — 1918；1945 — 至今（1918—1945 为法兰克共和国）
- **概述**：本世界线的西部日耳曼政治体。由哈布斯堡的鲁道夫在卡佩绝嗣后入主，定都帕里斯，宫廷与军事德意志化。1356年《法兰克福宪章》后与德意志王冠构成不可分割的双重王冠。1871年罗马加冕后与德意志王冠分离，成为独立国家。
